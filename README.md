# Учет личных финансов

Приложение для учета личных финансов с поддержкой транзакций, счетов и категорий.

## Технологии

- **Backend**: Node.js, Express, TypeScript, SQLite (better-sqlite3)
- **Frontend**: React, TypeScript, Vite
- **Контейнеризация**: Docker, Docker Compose

## Структура данных

### Таблица Transaction
| Поле | Тип | Описание |
|------|-----|----------|
| Id | GUID | Уникальный идентификатор |
| OwnerId | GUID | Ссылка на владельца |
| AccountId | GUID | Ссылка на счет |
| CategoryId | GUID | Ссылка на категорию |
| Amount | REAL | Сумма (точность 2 знака) |
| Type | INTEGER | -1 = расход, 1 = доход |
| Date | TEXT | Дата транзакции |

### Справочники
- **Owner** — владельцы счетов
- **Account** — счета (с привязкой к владельцу)
- **Category** — категории доходов/расходов (с привязкой к владельцу)

## Запуск приложения

### Вариант 1: Локальная разработка

#### Требования
- Node.js 20+
- npm 9+

#### Установка зависимостей
```bash
npm install
```

#### Запуск в режиме разработки
```bash
npm run dev
```

Приложение будет доступно:
- Frontend: http://localhost:3000
- Backend API: http://localhost:3001

#### Сборка для production
```bash
npm run build
```

#### Запуск production версии
```bash
npm start
```

### Вариант 2: Docker Compose

#### Требования
- Docker 20+
- Docker Compose 2+

#### Запуск
```bash
docker-compose up --build -d
```

Приложение будет доступно по адресу: http://localhost:3001

#### Остановка
```bash
docker-compose down
```

#### Просмотр логов
```bash
docker-compose logs -f
```

## Тестирование API (Bruno)

Проект включает коллекцию для тестирования API в [Bruno](https://www.usebruno.com/).

#### Использование:
1. Откройте Bruno
2. Нажмите "Open Collection"
3. Выберите папку `bruno/finance-api`
4. Запустите backend: `npm run dev:backend`

Коллекция содержит запросы для всех endpoints:
- Health Check
- Owners (CRUD)
- Accounts (CRUD)
- Categories (CRUD)
- Transactions (CRUD)

См. `bruno/finance-api/README.md` для подробностей.

## API Endpoints

### Владельцы (Owners)
| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | /api/owners | Получить всех владельцев |
| GET | /api/owners/:id | Получить владельца по ID |
| POST | /api/owners | Создать владельца |
| PUT | /api/owners/:id | Обновить владельца |
| DELETE | /api/owners/:id | Удалить владельца |

| PUT | /api/accounts/:id | Обновить счет |

## Функциональность

### Главная страница (Форма ввода)
- Создание новой транзакции
- Выбор типа операции (доход/расход) определяется автоматически из категории
- Выбор владельца, счета, категории
- Ввод суммы и даты

### Страница "Транзакции"
- Просмотр всех транзакций
- Отображение сводки (доходы, расходы, баланс)
- Удаление транзакций

### Страница "Справочники"
- Управление владельцами (CRUD)
- Управление счетами (CRUD)
- Управление категориями (CRUD)

## PWA (Progressive Web App)

Приложение поддерживает установку как PWA:

### Установка на iOS (Safari)
1. Откройте приложение в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой)
3. Выберите "На экран «Домой»"
4. Нажмите "Добавить"

### Установка на Android (Chrome)
1. Откройте приложение в Chrome
2. Нажмите меню (три точки)
3. Выберите "Добавить на главный экран"
4. Подтвердите установку

### Преимущества PWA
- Работает офлайн (кэширование API запросов)
- Быстрый запуск с главного экрана
- Автономный режим (без адресной строки браузера)
- Автоматическое обновление

## Хранение данных

- **Локально**: файл `backend/data/finance.db`
- **Docker**: том `finance_data` (персистентное хранение)

## Логирование

Логи backend сохраняются в `backend/logs/`:
- Файлы именуются как `server-YYYY-MM-DD.log`
- Логируются все запросы (метод, URL, статус, время выполнения)
- Логируются ошибки
